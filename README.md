# AI voice assistant for food ordering and reservation for restaurants

# How to run  
Step1 : Open a terminal. Head to app folder inside frontend. Run the frontend with commnad below.
npm run dev
Step2 : Open a new terminal and activate python virtual environment. Run the token server with below command
python server.py
Step3 ; Open another terminal and activate python virtual environment. Run the livekit agent in dev mode.
python restaurant_agent.py dev

Go to the localhost URL which frontend runs. Happy ordering!
